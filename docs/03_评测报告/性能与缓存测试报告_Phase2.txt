一、缓存命中率（维度二）
----------------------------------------------------------------------------------------
  口径说明：DeepSeek 的 prompt_tokens = 命中 token + 未命中 token，
            没有 cacheWrite（不另收写入费），因此
            命中率 = 命中 token / 输入 token
            与官方式 cacheRead/(input+cacheRead+cacheWrite) 完全等价。

  ① 缓存命中率        90.87%  （稳态口径，排除前 2 次冷启动）  标准 ≥70%   合格

  ③ 平均每请求命中     2,218 token / 次调用
