# 【为什么把版本钉死（==）而不是原来的 >= ？】
#
#   写 >= 时，pip 装的是「当天最新的兼容版」：
#   今天构建和下周构建可能装到两套不同版本 ——
#   于是别人复现不出你报告里的读数，CI 也可能因为上游发了新版而突然变红，
#   而变红的原因和你的改动毫无关系。**这种红最难查。**
#
#   钉死之后，「装出来的环境」变成可复现的输入，而不是碰运气的结果。
#
# 【这些版本号是怎么来的？】
#
#   不是手抄的，是 2026-09-19 在 python:3.11-slim 里**全新安装解析出来的结果**，
#   并在该环境下跑通了全部 743 条单测（见 docs/02_测试复盘/测试复盘记录.txt
#   第十二章）。也就是说：这一组版本是被验证过的组合，不是猜的。
#
# 【以后怎么升级？】
#
#   显式改这里的版本号，然后重跑测试与 CI ——
#   让「升级」是一个有意识、有验证的动作，而不是悄悄发生的副作用。
# ============================================================
